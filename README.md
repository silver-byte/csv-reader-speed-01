A fast, dependency-free drop-in equivalent of csv-reader 1.0.0: it reads broken CSV exactly as csv-reader does — the same columns, rows and errors on every input — in a single pass that slices fields out of the text instead of building them character by character.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
